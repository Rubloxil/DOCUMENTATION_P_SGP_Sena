# Restricciones del Sistema

## Restricciones Técnicas

### RT-01
El sistema deberá desarrollarse utilizando tecnologías backend como Node.js 18+ o PHP 8+.

### RT-02
La base de datos deberá ser relacional (PostgreSQL o MySQL).

### RT-03
El sistema deberá implementarse bajo arquitectura en capas (Presentación, Lógica de Negocio y Persistencia).

---

## Restricciones Operativas

### RO-01
El sistema solo contemplará dos roles en su versión inicial: Aprendiz e Instructor.

### RO-02
El sistema no incluirá analítica avanzada en la versión MVP.

---

## Restricciones de Seguridad

### RS-01
El acceso al sistema requerirá autenticación obligatoria.

### RS-02
Se deberá mantener registro de auditoría de acciones críticas.

---

## Restricciones de Recursos

### RR-01
El sistema deberá desarrollarse utilizando herramientas de software libre.

### RR-02
No se permitirá la contratación de servicios externos en la fase inicial.
