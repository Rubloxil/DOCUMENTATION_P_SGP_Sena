# Reglas de Negocio

### RN-01
Un aprendiz podrá tener máximo 3 proyectos activos simultáneamente.

### RN-02
Un proyecto no podrá cambiar a estado "Aprobado" sin revisión previa del instructor.

### RN-03
Solo instructores registrados podrán evaluar proyectos.

### RN-04
Los proyectos deberán conservarse en el sistema durante mínimo 5 años para fines académicos.

### RN-05
El sistema solo permitirá el uso de correos institucionales para registro.
